# THE SYSTEM — iPhone Home Screen App

## Publish it free with GitHub Pages
1. On a computer, sign in to GitHub and create a new **public** repository named `the-system`.
2. Upload all files in this folder to the repository's root (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your site address will look like `https://YOUR-USERNAME.github.io/the-system/`.

## Add it to your iPhone
1. Open the published HTTPS address in **Safari** (not an in-app browser).
2. Tap **Share** (square with arrow).
3. Scroll and tap **Add to Home Screen**.
4. Name it `THE SYSTEM`, enable **Open as Web App** if that option appears, then tap **Add**.

## Notes
- The app works offline after its first successful load.
- Progress and custom quests are saved locally in that browser on that device. They are not synced to iCloud or shared with other people.
- Use **Status → Export Save** to make a backup. Import it later from the same section.
- If you publish an update, refresh the site once while online. The service worker may take a moment to update.

- The app is free; GitHub Pages offers free static hosting for public repositories.
